Email Best Practices

  • Subject line — specific and actionable: "Q3 Report Review — Feedback by Friday"
  • CC vs BCC — CC is visible to all recipients; BCC is hidden (use for privacy)
  • Reply-All caution — only Reply All when the whole thread needs your response
  • Attachments — mention in body; use links for large files (>10MB)
  • Phishing — never click links or download files from unexpected emails
  • Professional tone — greeting, body, signature; proofread before sending

Internet Safety

  • Use strong unique passwords + a password manager (Bitwarden, 1Password)
  • Enable 2FA (Two-Factor Authentication) on all important accounts
  • Check for HTTPS (padlock icon) before entering passwords
  • Keep browser and OS updated — patches fix security vulnerabilities
  • Use a VPN on public WiFi (airports, cafes, hotels)
  • Never share personal info in reply to unsolicited messages

Lookup & Reference

=VLOOKUP(lookup,table,col_num,0)
  // Vertical lookup — 0 = exact match, 1 = approximate
  // Example: =VLOOKUP(D2,A:C,3,0)  → find D2 in col A, return col C

=XLOOKUP(lookup,lookup_array,return_array,"not found")
  // Modern replacement — searches left OR right, no col number
  // Example: =XLOOKUP(D2,A:A,C:C,"N/A")

=INDEX(A:A,MATCH(D2,B:B,0))
  // Flexible: find row of D2 in column B, return that row from A
  // Faster than VLOOKUP on large datasets

=HLOOKUP(lookup,table,row_num,0)  // Horizontal lookup (rows)
=MATCH(value,array,0)             // Position of value in array
=INDEX(array,row,col)             // Value at row/col position
=OFFSET(A1,2,3)                   // Cell 2 rows down, 3 cols right
=INDIRECT("A"&B1)                 // Dynamic cell reference

3. PivotTable — Step by Step

  1. Format data as a Table first: click anywhere in data → Ctrl+T → tick "My table has headers"
  2. Insert → PivotTable → New Worksheet
  3. In the PivotTable Fields pane drag fields to: Rows (group by), Columns (cross-tab), Values (aggregate), Filters (top filter)
  4. Values field settings: click ▼ next to field → Value Field Settings → choose Sum/Count/Average/Max/Min
  5. Show values as %: Value Field Settings → Show Values As → % of Grand Total
  6. Slicers: PivotTable Analyze → Insert Slicer — clickable filter buttons that look great in dashboards
  7. Refresh: PivotTable Analyze → Refresh (or Alt+F5) after data changes
  8. PivotChart: PivotTable Analyze → PivotChart — chart that auto-updates with the table

5. Excel Tables (Structured References)

Convert any data range to a Table with Ctrl+T. Tables are the single most impactful Excel feature for real work:

  • Formulas use names instead of cell refs: =SUM(Sales[Revenue]) instead of =SUM(C2:C500)
  • New rows automatically extend the table and all formulas
  • Auto-filter headers, banded rows, built-in styles
  • Total Row: Table Design → Total Row → pick aggregation per column
  • PivotTables built from Tables auto-include new rows on refresh

6. What-If Analysis

  • Goal Seek (Data → What-If → Goal Seek): work backwards — "what input gives me output X?" e.g. what interest rate gives a £500/month payment?
  • Data Table (Data → What-If → Data Table): show all outputs for a range of inputs. One-variable: one row of inputs + one formula. Two-variable: row inputs + column inputs.
  • Scenario Manager (Data → What-If → Scenario Manager): save named sets of input values (Best Case, Worst Case) and switch between them instantly
  • Solver (Data → Solver, requires Add-In): optimize a formula subject to constraints — budget allocation, scheduling, minimum cost

7. Power Query — Clean Data Fast

Data → Get Data → From File/Web/Database. Steps are recorded and replayed on refresh — never manipulate raw data manually again.

  • Remove Columns/Rows — right-click column header → Remove
  • Split Column — by delimiter, fixed width, or position
  • Unpivot — turn column headers into rows (critical for PivotTables)
  • Merge Queries — like SQL JOIN between two tables
  • Append Queries — stack tables (like SQL UNION)
  • Fill Down — fill merged cells with repeated values
  • Close & Load → loads cleaned data back to a worksheet as a Table

🏢 Enterprise IT Operations

How Corporate IT Departments Actually Run Things

Everything so far has been about using a computer. This section is about running IT for an organization — the systems, processes, and infrastructure that keep hundreds or thousands of employees' computers, accounts, and networks working together.

Active Directory Fundamentals

Active Directory (AD) is Microsoft's directory service — the central database of every user, computer, and group in a company, and the system that controls who can log into what.

ConceptWhat it means
DomainA logical boundary of users/computers managed under one security policy (e.g. corp.contoso.com)
Domain Controller (DC)A server that holds the AD database and handles login authentication for the domain
Organizational Unit (OU)A folder-like container used to organize users/computers and apply different policies to different departments
Group Policy (GPO)Rules pushed out to computers/users in an OU — e.g. "force a screen lock after 5 minutes" or "map this network drive"
TrustA relationship letting users in one domain access resources in another (common after company mergers)
LDAPThe protocol apps use to query AD — "is this username/password valid?", "what groups is this user in?"

In practice: when an employee logs into their work laptop, it's a Domain Controller checking their credentials against AD. When IT disables an account on someone's last day, that's an AD change that instantly revokes access everywhere tied to that account.

Windows Server Roles & Administration

A "role" is a function a Windows Server is configured to perform. One physical/virtual server often runs several roles.

RoleWhat it does
Active Directory Domain ServicesTurns the server into a Domain Controller
DNS ServerResolves internal hostnames (fileserver01) to IP addresses — AD depends on this working correctly
DHCP ServerAutomatically hands out IP addresses to devices joining the network
File & Storage ServicesShared network drives (e.g. the company's \\fileserver\shared)
Print ServicesCentrally manages network printers and their drivers/queues for all users

Server Manager is the main GUI for adding/removing roles and monitoring server health; most of this can also be scripted with PowerShell (see the Online IDE & Dev Tools portal for PowerShell scripting basics).

Enterprise Networking

ConceptWhat it solves
VLANSplits one physical network into multiple isolated logical networks (e.g. "Finance VLAN" can't see "Guest WiFi VLAN") without needing separate cabling
Routing (OSPF/BGP basics)OSPF finds the best path for traffic within an organization's own network; BGP is the protocol that routes traffic between different networks across the internet
FirewallA standalone network appliance (not just a per-PC setting) that filters traffic between network zones — e.g. blocking the Guest WiFi VLAN from reaching internal servers entirely
Load BalancerDistributes incoming traffic across multiple servers so no single server gets overwhelmed and the service stays up if one server fails

These are the building blocks behind "why can't I access the file server from the guest WiFi" or "why did the website go down when one server crashed but come right back."

ITIL / ITSM — How IT Support Is Organized

ITIL (IT Infrastructure Library) is the most widely used framework for running an IT service desk. It defines standard processes so that "someone's laptop is broken" and "we need to change the email server" are handled consistently instead of ad hoc.

ProcessPurposeExample
Incident ManagementRestore normal service ASAP"My laptop won't turn on" → ticket → fixed today
Problem ManagementFind and fix the root cause behind recurring incidents20 laptops failed this month with the same issue → investigate the common cause
Change ManagementReview and approve changes before they hit production systems"We want to upgrade the email server this weekend" → change request → approval → scheduled maintenance window

Service desk tiers: Tier 1 (help desk) handles common requests like password resets; Tier 2 (desktop/network support) handles harder technical issues escalated from Tier 1; Tier 3 (specialists/engineers) handles the most complex problems, like a server outage.

Microsoft 365 & Exchange Online Administration

Most companies no longer run their own email server — they use Microsoft 365, and an IT admin manages it centrally through the Microsoft 365 Admin Center instead of logging into individual machines.

  • User & license management — create accounts, assign licenses (Business Basic, E3, E5), reset passwords centrally
  • Exchange Online Admin Center — manage mailboxes, distribution lists, shared mailboxes, mail flow rules (e.g. block attachments over 25MB)
  • Teams Admin Center — control who can create Teams, external guest access, meeting policies
  • SharePoint/OneDrive admin — storage quotas, external sharing policies, retention/compliance rules
  • Security & Compliance Center — enforce MFA, data loss prevention (DLP) policies, audit logs for "who accessed this file"

MDM & BYOD

Mobile Device Management (MDM) lets IT manage phones/laptops remotely — enforcing security policy, pushing apps, and wiping a device if it's lost or stolen — whether the device is company-owned or an employee's personal device enrolled under a BYOD (Bring Your Own Device) policy.

CapabilityWhy it matters
EnrollmentA device must be registered with the MDM (e.g. Microsoft Intune, Jamf for Apple) before it gets corporate access
Policy enforcementRequire a PIN/biometric lock, disk encryption, minimum OS version before allowing email access
Remote wipeIf a device is lost/stolen, IT can wipe just the corporate data (BYOD) or the entire device (company-owned)
App managementPush required apps automatically, block unauthorized ones (an "app allowlist")

Backup & Disaster Recovery (Enterprise)

The 3-2-1 backup rule covered earlier applies at home too — but at enterprise scale, IT also needs a formal disaster recovery plan: not just "do we have a backup" but "how fast can we actually be back up and running."

TermMeaning
RTO (Recovery Time Objective)How long can the system be down before it's a crisis? (e.g. "4 hours")
RPO (Recovery Point Objective)How much data can we afford to lose? (e.g. "1 hour" = backups must run at least hourly)
Backup mediaDisk-based backups are fast to restore; tape is cheaper for long-term archival/compliance retention and is still common for the "offline, offsite" copy

IT Asset & Peripheral Management

Enterprise IT tracks every laptop, monitor, phone, and license the company owns — not for its own sake, but because it answers questions like "who has this laptop," "is this software license expired," and "what do we need to wipe when an employee leaves."

  • Asset tags & inventory — every device gets a unique ID tracked in an asset management system (ServiceNow, Snipe-IT) tied to the employee who has it
  • Software license management — tracking how many licenses are owned vs. in use, avoiding both overspending and compliance violations from unlicensed software
  • Print server management — centrally deploying printer drivers and managing print queues so users don't install drivers individually on every machine
  • Lifecycle management — procurement → deployment → maintenance → end-of-life wipe/disposal, often on a 3-4 year refresh cycle

API (Application Programming Interface) — A set of rules for how software applications communicate with each other. Like a menu in a restaurant — lists what you can order (request) and what you'll get back.
Algorithm — A step-by-step procedure for solving a problem or completing a task. Like a recipe for code.
B
Bandwidth — The maximum data transfer rate of a network connection. Measured in Mbps or Gbps.
Bit / Byte — Bit = smallest unit (0 or 1). Byte = 8 bits. 1 KB = 1024 bytes, 1 MB = 1024 KB.
Bluetooth — Short-range wireless technology (typically 10m) for connecting devices (headphones, keyboards, mice).
C
Cache — Temporary storage for frequently accessed data. Web browsers cache pages; CPUs cache instructions for speed.
Cloud Computing — Using remote servers (via the internet) to store, manage, and process data instead of local hardware. Examples: AWS, Azure, Google Cloud.
CPU (Central Processing Unit) — The primary chip that executes program instructions. The "brain" of the computer.
Cybersecurity — Protecting systems, networks, and programs from digital attacks, unauthorized access, and data theft.
D
Database — Organized collection of structured data. Types: Relational (SQL tables), NoSQL (documents, key-value).
DNS (Domain Name System) — The internet's phone book — translates human-readable domain names (google.com) to IP addresses (142.250.80.46).
E
Encryption — Converting data into a coded form that can only be read by authorized parties with a key. Used in HTTPS, passwords.
Ethernet — Wired networking technology using cables (Cat5e, Cat6) for high-speed, reliable connections.
F
Firewall — Network security system that monitors and controls incoming/outgoing traffic based on security rules.
Framework — Pre-built code structure that provides a foundation for application development. Examples: React (frontend), Django (backend).
H
Hardware — Physical components of a computer: CPU, RAM, SSD, motherboard, monitor, keyboard, mouse.
HTTP/HTTPS — HyperText Transfer Protocol — the foundation of web communication. HTTPS adds TLS encryption (padlock in browser).
I
IP Address — Unique numerical label for every device on a network. IPv4: 192.168.1.1 (4 octets). IPv6: longer hex format for more addresses.
IoT (Internet of Things) — Network of physical devices embedded with sensors/software that connect and exchange data over the internet.
L
LAN (Local Area Network) — Network connecting computers in a limited area (office, home). Uses switches and routers.
M
Malware — Malicious software: viruses, trojans, ransomware, spyware, adware. Spread via email attachments, downloads, websites.
Memory (RAM) — Random Access Memory — temporary, volatile storage where the CPU keeps data it's currently using. More RAM = smoother multitasking.
N
Network — Group of interconnected devices that communicate and share resources (files, printers, internet).
O
Open Source — Software with publicly available source code that anyone can view, modify, and distribute. Examples: Linux, Firefox, Python.
OS (Operating System) — Software that manages hardware and provides services for applications. Examples: Windows, Linux, macOS, Android.
P
Phishing — Social engineering attack via fraudulent emails/messages designed to steal credentials, credit cards, or install malware.
Protocol — Set of rules governing how data is transmitted. Examples: HTTP, TCP/IP, FTP, SMTP, SSH.
R
Router — Networking device that forwards packets between networks. Connects your LAN to the internet via the ISP.
S
SaaS (Software as a Service) — Cloud-delivered software accessed via browser. Examples: Gmail, Salesforce, Microsoft 365, Slack.
Software — Programs and operating information used by a computer. Opposite of hardware.
SSL/TLS — Protocols that encrypt data in transit. TLS 1.3 is current. Creates the HTTPS padlock in browsers.
T
TCP/IP — Transmission Control Protocol/Internet Protocol — the fundamental communication protocol suite of the internet.
U
UI/UX — User Interface (visual design) / User Experience (overall feel and usability). Good UX makes software intuitive and satisfying.
USB — Universal Serial Bus — standard connector for peripherals (drives, keyboards, charging). USB-A, USB-C, USB 3.2 are common types.
V
Virtualization — Running multiple virtual machines on one physical host using software (VMware, VirtualBox, Hyper-V).
VPN (Virtual Private Network) — Encrypts your internet traffic and routes it through a remote server, masking your IP and location.
W
WiFi — Wireless networking using radio waves (802.11 standard). WiFi 6 (802.11ax) offers up to 9.6 Gbps theoretical speed.
WAN (Wide Area Network) — Network spanning large geographic areas. The internet is the largest WAN.
