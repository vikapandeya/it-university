Word Golden Rule
Always use Styles (Heading 1/2/3, Normal) — never format text manually. Enables auto-TOC, consistent formatting, and easy theme changes.
Excel Golden Rule
Start every range with Ctrl+T (Table). Structured references, auto-expand, and PivotTable refresh come free.
F4 Trick
In an Excel formula: press F4 to cycle A1 → $A$1 → A$1 → $A1
Repeat Last Action
F4 in Word / Ctrl+Y anywhere — repeats the very last action (format, delete, insert row)

* — any string of characters

[a-z] — range of characters

PivotTable Quick Guide

Insert → PivotTable
1. Click in data → Ctrl+T (make it a Table)
2. Insert → PivotTable → New Worksheet
3. Drag fields to Rows / Columns / Values / Filters
4. Values: click ▼ → Value Field Settings → Sum/Avg/Count
5. Show as %: Value Field Settings → Show Values As
6. Add Slicer: PivotTable Analyze → Insert Slicer
7. Refresh data: Alt+F5 or Analyze → Refresh
8. PivotChart: Analyze → PivotChart
Group dates: right-click a date cell in the PivotTable → Group → choose Year/Quarter/Month to auto-group.

Cell Reference Types

Press F4 to cycle
TypeSyntaxWhen copied...
RelativeA1Row & col both shift
Absolute$A$1Nothing moves — fixed
Lock col only$A1Col stays, row shifts

F4 shortcut: while editing a formula, click a cell reference and press F4 to cycle through all 4 types instantly. Use $A$1 for tax rates, discount %, and any value used across many rows.
