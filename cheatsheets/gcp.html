IAM Deep Dive — Predefined Roles

Configuring Access & Security
Most-Tested Predefined Roles
RoleGrants
roles/viewerRead-only on almost everything
roles/editorViewer + modify existing resources
roles/ownerEditor + manage roles/permissions + billing
roles/iam.securityAdminManage IAM policies, not resources
roles/iam.serviceAccountUserAttach/impersonate a service account
roles/iam.serviceAccountTokenCreatorMint short-lived tokens for a SA
roles/resourcemanager.projectIamAdminManage project-level IAM, not resources
roles/billing.userLink a project to a billing account
roles/storage.objectViewerRead objects, not delete/list buckets
roles/storage.adminFull control on buckets + objects
roles/compute.instanceAdmin.v1Manage VMs, not networking/firewalls
roles/compute.networkAdminManage networking, not firewall rules
roles/compute.securityAdminManage firewall rules and SSL certs only
Interview trap: instanceAdmin ≠ networkAdmin ≠ securityAdmin for Compute — Google deliberately splits VM lifecycle, network config, and firewall/SSL into three separate roles for least-privilege design.
Policy Evaluation Order
1Deny policies evaluated first (IAM Deny, if configured) — explicit deny always wins
2Allow policies at resource, then merged with inherited allow policies up the hierarchy
3Effective permission = union of all applicable allow bindings, minus any deny

Scenario Q&A — Interview Style

Answer in one clear sentence, then justify — 24 scenarios
Compute & Architecture Choice
Q: You need to run untrusted third-party containers with zero server management.
ACloud Run — scale-to-zero, fully managed, isolated per-request execution.
Q: A legacy app requires kernel-level access and specific OS patches. Where does it run?
ACompute Engine — the only compute option giving you full OS control.
Q: You must run a nightly batch job that takes 3 hours and can tolerate interruption.
ACloud Run Jobs or Batch on Spot VMs — run-to-completion, cheap, restart on preemption.
Q: An app has 100s of microservices needing service discovery, retries, and mTLS.
AGKE + Anthos Service Mesh — mesh features aren't native to Cloud Run/Functions.
Q: Why would GKE Autopilot be rejected for a specific workload?
AIt restricts privileged containers, hostPath volumes, and DaemonSets — workloads needing those must use Standard mode.
Q: How does Compute Engine live migration affect a scheduled maintenance event?
AThe VM is transparently moved to another host with no reboot — unlike AWS/Azure, which typically require a stop/start.
Q: A workload needs a GPU for short ML training bursts, cost is the top priority.
AA2/G2 Spot VM — up to 91% off, acceptable since training checkpoints can resume after preemption.
Q: What differentiates App Engine Standard from Flexible?
AStandard = sandboxed runtimes, scales to zero in seconds; Flexible = Docker on VMs, slower scaling, more customization.
Data, Storage & Analytics
Q: A team needs a globally consistent SQL database for a financial ledger.
ACloud Spanner — the only GCP DB offering horizontal scale + external (strong) consistency across regions.
Q: How do you prevent an analyst from seeing a salary column but let them query the rest of the table?
AApply a column-level security policy tag via Data Catalog, or expose an authorized view that excludes the column.
Q: A BigQuery table is scanned in full on every query and costs are spiking. What's the fix?
AAdd date partitioning and cluster on the most-filtered column — this prunes bytes scanned before billing.
Q: You need sub-10ms reads on billions of IoT time-series rows.
ACloud Bigtable — wide-column store built for exactly this throughput/latency profile.
Q: Mobile app needs offline-first data with automatic real-time sync when reconnected.
AFirestore — native offline persistence and live listeners in the client SDKs.
Q: You must analyze data sitting in an S3 bucket without copying it into GCP first.
ABigQuery Omni — runs BigQuery compute against data in place on AWS/Azure.
Q: A 2TB nightly file must be archived and almost never read again — cheapest option?
ACloud Storage Archive class — cheapest storage cost, accept the higher retrieval cost/latency and 365-day min.
Q: You need one unified pipeline that handles both historical batch and live streaming data.
ADataflow (Apache Beam) — same pipeline code runs in batch or streaming mode.
Networking & Security
Q: How do you let a Compute Engine VM with no public IP call the Cloud Storage API?
AEnable Private Google Access on its subnet — traffic to Google APIs stays on Google's network.
Q: Your GKE cluster needs pods to access GCS without service account key files.
AEnable Workload Identity — bind the Kubernetes service account to a Google service account.
Q: Two VPCs in different projects need full bidirectional connectivity.
AVPC Peering (non-transitive) — or Network Connectivity Center if more than 2 VPCs need hub-spoke reachability.
Q: A public web app is getting hit by a Layer 7 DDoS/SQLi attack. What do you add?
ACloud Armor in front of the Global External HTTP(S) Load Balancer — WAF rules + edge DDoS mitigation.
Q: Private VMs need outbound internet for OS updates but must never accept inbound connections.
ACloud NAT — outbound-only managed NAT gateway, no inbound path exists by design.
Q: You must connect on-prem to GCP with guaranteed low latency and no public internet hop.
ADedicated Interconnect — private circuit directly into Google's network, not IPsec over the internet like VPN.
Q: A contractor needs temporary access to one project only, revoked automatically after 30 days.
AIAM Conditions on the role binding — set a time-based expression so access self-expires.
Q: How do you stop any engineer from ever creating a service account key across the whole org?
ASet the Org Policy constraint iam.disableServiceAccountKeyCreation at the organization node — inherits to every project.

Common Traps to Avoid
⚠GCP VPC is GLOBAL — subnets are regional, not zonal.
⚠Sustained-use discount is automatic; committed-use requires a contract.
⚠Firewall rules apply at VPC/network level, not subnet level.
⚠Cloud Armor only protects the Global External HTTP(S) LB.
⚠Spot/Preemptible VMs can be reclaimed anytime — never for stateful critical workloads.
⚠IAM policy inherits down the hierarchy — cannot be revoked at a lower level, only added.
⚠Storage class ≠ location type — pick storage class AND location independently.
⚠Project ID is immutable once created; Project Name is not.
